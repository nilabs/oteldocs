    Выгрузка данных табелей для ЗУП

    1. Выгрузка данных графиков сотрудников Отель-ЗУП

      Для выгрузки данных в табель ЗУП, откройте  форму заполнения  графиков рабочего времени сотрудников (меню  «служба номеров → График рабочего времени сотрудников)
















      Проверьте заполненные данные за необходимый период, используя фильтры в форме
      (Отдел, сотрудник и т.д.).

      Убедитесь, что каждый заполненный сотрудник в форме имеет ФИО в полном формате
    2. Иванов Иван Иванович (а не Иванов И.И.), (имена в Двине исправлены по текущим сотрудникам).

      В панели действий, откройте обработку (Печать и выгрузка — Выгрузка табеля)

      Выберите период данных (по умолчанию устанавливается предыдущий месяц от текущей даты).
      Выберите присланный из ОУП (или сохраненный  в сети ??? пока неизвестно) Вам файл-шаблон в обработке, пример - «Гостиница Двина за 122020.xls»
      (файл-шаблон содержит данные актуальных сотрудников, с проставленными днями отпусков, больничных и т. д., по данным базы Зарплата и управление персоналом).
      Если до этого файл был открыт в  офисной программе — закройте офисную программу.
      (при открытом в другой программе файле, в файл нельзя ничего записать)






      Нажмите кнопку «Выгрузить в табель EXEL”
      Данные будут сформированы и открыты в 1С. При отсутствии ошибок Вы отправляете (или сохраняете файл для ОУП)






      При наличии ошибок в выгрузке, в окне сообщений будут выданы предупреждения, тем не менее файл xls откроется.


      В настоящий момент описано 2 ошибки:
    3. На сотрудника Иванов Иван Иванович данные в  базе не заполнены.
       - не заполнен график на сотрудника за выбранный в обработке период
    4. Петров Петр Петрович не найден в справочнике сотрудников.
        - программа не нашла в базе сотрудника, но возможно он есть.
          Формат Наименования сотрудника должен быть «Фамилия Имя Отчество» - 1 пробел между словами (может быть Фамилия Имя) — так как он занесен словами.

      Алгоритм поиска сотрудника сначала ищет его по табельному номеру
       (по умолчанию они не заполнены)







      Если сотрудник не найден, начинает искать его по ФИО.
      Найдя его по ФИО, заполняет ему табельный номер, если он не установлен.


      Алгоритм заполнения данных о рабочем времени:

      Шаблон ЗУП - первоначальный файл-табель, представляемый отделом ОУП для заполнения.
      Выгрузка данных — заполненный данными файл, представляемый в отдел ОУП.

      1.В выгрузку данных новые сотрудники из базы 1С Отель не добавляются.
         Заполняются только найденные сотрудники.

      2.Шаблон ЗУП частично заполнен данными введенными отделом ОУП.
    5. Данные нерабочего времени (ОТПУСК, БОЛЬНИЧНЫЙ и т.д.) из шаблона ЗУП приоритетны над данными 1С:Отель. Эти дни пропускаются для заполнения (Остаются первоначальные значения из ЗУП)
    6. Из 1С: ОТЕЛЬ выгружаются данные часов явки (проставленные числовые значения) и код неявки «НН» (неявка по невыясненным причинам (до выяснения обстоятельств)),
      код занесен в справочник.

      Остальные буквенные коды не переносятся (в будущем возможны изменения в процессе эксплуатации).
