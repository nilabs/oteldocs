    Переселение из номера в номер

    Переселение из номера в номер
    (все данные условны и не из рабочей базы)

    Первоначальное размещение.





    Создается новое размещение


    В  основании документа размещения будет предыдущее размещение.


    В списке проживающих останется текущее размещение, в архиве размещений 2 (на одного человека)

    | | |
    |-|-|
    | | |
    |   |   |

    В лицевом счете на владке клиенты будут отображены номера проживания.


    В истории первоначального размещения появится запись смены статуса




    Если переселение происходит >1 часа от времени поселения, то у первоначального номера будет выставлен статус «грязный», меньше  - он возвращается в статус свободный (фритайм), при этом документа переселения не создается  - изменяется первоначальный документ размещения.

    !!! Дальнейшие действия со статусом номера ** сотрудники ресепшен ** должны совершить самостоятельно , программа не знает чистый он или грязный.



    !!! Изменение статусов верно для сотрудников с правами «ресепшен», любые иные сотрудники не должны производить переселение. (будет заблокирована возможность.)



    Начисления:
    Если переселение происходит в первые сутки проживания, то существует проблема с начислениями,
    Первоначальный документ:

    первоначальная сумма 9150, после 10980.

    после переселения – первоначальный документ:

    документ переселения.


    В настоящий момент данная ситуация не может быть быстро исправлена (связана с оригинальными начислениями раннего и позднего заезда) и сотрудникам необходимо проводить корректировку начислений вручную
